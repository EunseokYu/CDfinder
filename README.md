# cdfinder

미니멀한 CD판 다나와 — 사고 싶은 CD를 등록해 두면 판매처를 주기적으로 확인하고, 같은 조건의 CD를 지금 어디서 얼마에 살 수 있는지 보여준다.

## 탐색 주기
- **빠른 회차 (15분마다)**: 외부 호출(cron-job.org → `workflow_dispatch`). 중고나라 새 매물 발견 + 유력 후보 원본 재확인.
- **1시간 회차 (매시 7분)**: GitHub 예약 `cron: '7 * * * *'` (또는 직전 1시간 회차 후 55분 경과 시 자동). 알라딘·YES24·음반점 조회와 추적 매물 전체 재확인.
- 앱 실행·새로고침은 저장된 최신 결과(`data/db.json`)를 읽기만 한다.

## 판매처
| 판매처 | 발견 | 개별 원본 검증 |
|---|---|---|
| 알라딘 신품 | 음반 검색 | 상품 페이지 JSON-LD 재고·가격, `Disc : N장` |
| 알라딘 판매자 중고 | 판매자 중고 목록(판매자별 개별 상품) | 개별 중고 상품의 구매 버튼·판매가·판매자 배송료·등급 |
| 중고나라 | 검색(제목), 모호한 제목은 본문 확인 | 상품 페이지 JSON-LD 재고·가격, 배송 옵션, 본문 |
| 음반점 (`data/stores.json`) | 카페24 상품 검색 | 상품 페이지 품절 표시·재고 수량·가격·배송비 |
| 번개장터 | 꺼짐 — 해외 서버에서 API 404, 상품 페이지 빈 화면 | — |
| YES24 | 실패 — 해외 서버 요청이 메인으로 리다이렉트 | — |
| 헬로마켓 | 제거 (과거 기록만 보존, 현재 판단 제외) | — |

## 판단 원칙 (`engine.js`)
- 자동 수집 매물은 최근 3시간 내 개별 원본 검증에 성공한 관측만 추천·최저가·평균가·참고 시세·알림에 쓴다. 검색 요약값은 발견에만 쓴다.
- 총액 = 상품가 + 필수 배송비. 배송비 미상은 총액 미확인(최저가·알림 제외). 매장 수령은 따로 비교.
- 판매완료·품절·절판·예약중·숨김·삭제·입고 예정·재고 문의는 제외. LP·카세트·굿즈·빈 케이스·구매글·일괄 판매는 제외.

## 파일
- `engine.js` 판단·통계 (웹앱·수집기 공용) · `scanner/run.js` 수집기 · `data/db.json` 데이터 · `data/stores.json` 음반점 목록 · `data/scan-report.json` 최근 스캔 결과
- `tests/run-tests.js` 실제 페이지 원본(`tests/fixtures`)과 DB 사본으로 검증 (`node tests/run-tests.js`)
- `.github/workflows/probe.yml` 새 판매처 진단용 (결과는 임시 브랜치 `probe-out`)

비밀 값(선택): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
